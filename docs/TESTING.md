# 验证范围

本包把“通用格式”“可迁移脚本”和“目标软件可用”分开验证。

## 自动检查

- Python 标准库测试：换目录后仍可读取内置规则、安装器拒绝覆盖、环境检查不改文件、媒体相对路径可重定位、越界路径被拒绝、非法时间和轨道冲突被拒绝。
- 包检查：内部引用、Python 语法、必要许可证，以及明显私人路径/凭据模式。
- GitHub Actions 在 Windows、macOS、Linux 上运行以上检查。运行状态以仓库 Actions 中对应提交的结果为准，不以配置了工作流就称已通过。

## 实际剪辑冒烟测试

使用新生成的测试画面和合成测试音，不使用用户私有素材，在隔离目录创建草稿。检查画面、旁白、原声、BGM、字幕是否有独立轨道，源入点与成片起点是否按计划保存，以及迁移后的计划能否重新解析。

这类测试确认程序写出了符合预期的数据；仍不能证明任意版本剪映会正常显示、播放或导出。

2026-09-28 的本地 Windows / Python 3.14 测试已完成：生成了 1 条视频轨、3 条独立音轨和 1 条字幕轨；视频源入点 0.5 秒，三条音轨源入点分别为 0.2、0.5、1 秒；复制到含中文及空格的新目录后，按相对计划重新生成成功。没有操作实际剪映界面，也没有导出 MP4。

复现命令：`python scripts/smoke_test_video.py`。需要 `pymediainfo` 和系统 FFmpeg；没有系统 FFmpeg 时可另装 `imageio-ffmpeg` 供这个测试使用，测试脚本不会自动安装依赖。

## 尚需真实设备验收

- 各剪映版本实际打开、播放、字体与字幕显示、导出。
- 不同 agent 对“方向不明先问”“用户观点优先”“去 AI 味只做白名单修改”的真实交互表现。
- 云端/手机环境的文件、联网和应用控制能力。

请在自己的目标设备记录系统、agent、剪映版本、作品类型和实际检查结果。不要将某台设备成功概括成所有平台完成验收。
